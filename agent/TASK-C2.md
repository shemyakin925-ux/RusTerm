## C2.1. Одна кнопка, которая собирает

**Done when:**
- из окна запускается сбор по выбранному эмитенту: провайдер → сырьё →
  факты → снапшот, тем же путём, что CLI;
- **логика не продублирована**: окно зовёт ядро, а не повторяет тело
  `cmd_ingest`. Если тело неотделимо от CLI — строка в Disputed с
  именем функции, а обходной копии не пиши;
- длинная операция идёт **не в UI-потоке** (ADR-0004 §3): окно не
  замерзает, виден прогресс, есть отмена;
- отмена действительно отменяет: после неё в базе нет половины
  снапшота. Тест на это.
