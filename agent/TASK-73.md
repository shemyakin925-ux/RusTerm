## T0. Измерено координатором на базе пользователя

База: 5 бумаг (AAPL, ADBE, VZ, VALE, KSPI), 10 снапшотов, 280 мер —
собрана обычным путём `add` → `ingest` → `snapshot`.

| Вкладка | Что показывает на этой базе | Причина |
|---|---|---|
| Компания | числа есть; **годовые колонки пусты всегда** | `measure_history()` возвращает `{}` (ТЗ-72) |
| Отрасль | «у компании нет peer set» и больше ничего | `peer_set` 0 строк, `industry_aggregate` 0, колонки сектора у эмитента нет; `rusterm industry` требует `--sector`, которого взять негде |
| Качество | покрытие настоящее (ADBE 20/28); governance — 5 серых строк `no_data:not_collected` | `ownership_transaction` 0 строк: канал владения в обычный путь не входит |
| Настройки | работает: ключи с происхождением без значений, лимиты, каталог | — |

**Диагноз одной фразой: окно показывает возможности, входы для
которых обычный путь не производит.** Это та же порода, что
`measure_history`, только шире: экран построен, наполнить его нечем,
и пользователю никто не говорит чем.

## T1. Правило, которое закрывает породу целиком

**Done when:**
- в `agent/PROTOCOL.md` (правку разрешаю только этим пунктом) одной
  строкой: **экран не показывает раздел, который не может
  наполниться; он либо наполняется, либо называет действие, которым
  наполняется, либо не рисуется**;
- тест-страж: для каждой вкладки окна на базе, собранной обычным
  путём, проверяется, что она либо несёт данные, либо несёт
  **исполнимую подсказку** (строка разбирается парсером CLI, как
  B26/J3). Пустая вкладка без подсказки — красный;
- страж показан красным на нынешних «Отрасли» и «Качестве».

## T2. Отрасль: сектор и peer set появляются обычным путём

**Done when:**
- у эмитента есть отрасль, и она **берётся из источника**, а не
  вводится руками: SEC отдаёт SIC-код в submissions — сопоставь его
  с сектором словаря (таблица соответствия — часть работы, её
  происхождение назови);
- `peer_set` строится по отрасли автоматически (правило отбора —
  словами в отчёте и в docstring), либо, если это решение спорное,
  строится **по команде одним действием**, и окно эту команду
  предлагает;
- после обычного пути на пяти бумагах пользователя вкладка «Отрасль»
  показывает таблицу, а не сообщение; проверено прогоном, числа в
  отчёт;
- `industry_aggregate` перестаёт быть нулевым: назови, сколько строк
  появилось и по каким секторам.

## T3. Качество: governance перестаёт быть пятью серыми строками

**Done when:**
- канал владения (формы 3/4/5) входит в обычный путь: либо `ingest`
  собирает его тем же вызовом, либо окно предлагает исполнимую
  команду прямо во вкладке;
- после сбора у AAPL и ADBE **хотя бы один** показатель governance
  перестаёт быть серым; какой именно и почему — в отчёт;
- показатели, которые остаются серыми, несут причину из словаря и
  строку «чем закрывается» (proxy через ручной импорт — назови путь);
- ни одной выдумки: нет данных — серый с причиной, а не догадка.
