## Решения, которые уже приняты — не пересматривать

- **Только `tkinter`.** `pyproject.toml` объявляет
  `dependencies = []`, пункт 11 приёмки гоняет набор без сторонних
  пакетов. Qt, Electron, Tauri, web-стек — отказ. `tkinter` есть в
  стандартной библиотеке (проверено, Tk 9.0).
- **Первый круг — только чтение.** Ни одной кнопки, которая собирает,
  обновляет, пишет в базу или зовёт сеть. Причина: действия живут в
  `cmd_*` внутри `rusterm/cli/__init__.py` (1604 строки, говорит
  `print`), это чужая территория и отдельная работа.
- **Данные берутся из `rusterm/tui/model.py`**, который уже отдаёт
  строки экрана без curses (`list_rows`, `card_rows`, `source_panel`,
  `industry_rows`). Свой слой чтения не пиши: если модели чего-то не
  хватает — строка в Disputed, а не новая функция в чужом файле.
- **Точка входа — `python3 -m rusterm.desktop`.** Команду
  `rusterm desktop` в CLI не регистрируй: `cli/__init__.py` — чужой
  файл. Регистрацию сделает полоса A позже.
- **Раздачи приложения не будет.** Подпись и нотаризация macOS —
  платные (ADR-0018). Окно запускается локально.

## C1.1. Окно со списком наблюдения

**Done when:**
- `python3 -m rusterm.desktop --root <каталог>` открывает окно со
  списком наблюдения; строки — из `list_rows`, ничего не досчитано
  на месте;
- пустая база — это не пустое окно и не трассировка: окно говорит
  словами, что смотреть нечего и что сделать (командой CLI);
- отсутствующего каталога данных окно **не создаёт** — то же правило,
  что B35/B40 для команд только-чтения. Тест на это;
- рисование отделено от данных так же, как `app.py` от `model.py`:
  модуль с данными импортируется и тестируется **без дисплея**.

## C1.2. Карточка и панель источника

Главное правило проекта: у числа есть происхождение.

**Done when:**
- выбор строки открывает карточку эмитента (`card_rows`), в ней —
  панель источника (`source_panel`) для выбранной меры;
- у каждого показанного числа видно, откуда оно: документ, дата,
  ссылка на сохранённый ответ. Не «есть где-то», а на экране;
- мера без значения показывает **причину словами** из словаря
  причин, а не пустую клетку и не прочерк. Тест на это — на мере,
  которая сейчас отказывает (CNQ `roe`, `missing_data: total_equity`);
- ни одна причина не переведена на глаз: текст берётся из того же
  источника, что и в CLI.

## C1.3. Тесты без дисплея

Tk требует дисплея, приёмка — нет.

**Done when:**
- весь слой данных десктопа покрыт тестами, которые идут без
  открытия окна; ни один тест не требует `DISPLAY`;
- отдельный тест помечен маркером и пропускается там, где дисплея
  нет: он проверяет, что окно **строится** (виджеты созданы) — без
  скриншотов;
- `python3 -m pytest` целиком зелёный на машине без дисплея — покажи
  прогоном, как именно проверил.
