## B1.1. Перепись «зелёных, которые не заслужили»

ТЗ-58 C4 снял `clip()` у `effective_tax`, который превращал настоящие
−0.2381 в зелёный 0.0. Вопрос шире: **где ещё** мера подгоняет
значение вместо отказа.

**Done when:**
- пройдено по **всем** мерам `rusterm/formulas.py`: для каждой названо,
  что она делает со входом вне ожидаемой области — отказ, зажим,
  деление на ноль, молчаливый ноль, `None`, отрицательное там, где
  отрицательного быть не может;
- таблица «мера → поведение вне области → честно/нечестно» в отчёте,
  все меры до одной, без пропусков;
- каждый **нечестный** случай закрыт отказом с причиной из словаря и
  тестом на граничный вход. Если нечестных больше пяти — закрой пять
  и перечисли остальные строками, с указанием, какие дешевле;
- ни одно золото не переписано без строки в сообщении коммита: какая
  мера, какое значение было, какое стало, почему.
