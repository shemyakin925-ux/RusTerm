## C1. `verify` не наследует мусор

**Done when:**
- путь рабочего дерева `verify` по умолчанию **уникален на прогон**
  (например, с меткой времени или коротким sha), а не общий на машину;
- если путь передан явно и в нём есть неотслеживаемые файлы — `verify`
  **не чистит молча**: печатает их список и отказывает с командой,
  которой их убрать; чистка по умолчанию запрещена — это чужие файлы;
- тест в отдельном каталоге (`tmp_path`): дерево с неотслеживаемым
  файлом → отказ с его именем; чистое дерево → прогон идёт;
- в отчёте: сколько каталогов `rusterm-relay-verify*` лежало в
  `tempfile.gettempdir()` на твоей машине до правки — число.
