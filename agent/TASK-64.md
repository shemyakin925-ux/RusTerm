## J2. Происхождение в экспорте CLI

Обещание проекта — у каждого числа есть происхождение. В окне оно
есть, в `rusterm export` — нет. Значит обещание держится только на
одной поверхности из двух.

**Done when:**
- `export --format json` несёт происхождение по каждой мере со
  входами: документ, дата, хэш сохранённого ответа — тем же путём
  по lineage, что десктопный экспорт, без второй реализации;
- `--format md` несёт источник в сноске (форма — твоя, но документ
  и дата обязательны);
- тест: ни одна строка **со значением** не уходит из экспорта без
  происхождения; строка с отказом несёт причину, а не пустоту;
- старые золотые файлы экспорта обновлены одним коммитом с
  объяснением, что изменилось.
