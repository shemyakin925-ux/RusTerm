Правило ТЗ-72 Д1 действует и для **частично** пустой таблицы: столбец,
в котором ни одна мера не имеет значения, — это обещание данных,
которых нет.

**Done when:**
- колонка года рисуется, только если хотя бы одна мера имеет значение
  за этот год; прочие не рисуются вовсе;
- если после отбора остаётся **один** год — это законно: одна колонка
  лучше четырёх пустых; проверь, что таблица в этом случае не
  разъезжается;
- если не остаётся ни одного — работает прежнее правило: колонок нет,
  `suggestion` несёт исполнимую строку;
- окно говорит словами, **почему** лет мало: одна строка вида
  «история за 1 год: снапшоты с <дата> по <дата>» — из данных, не из
  константы;
- тест на настоящей форме данных: база, где мера имеет значение только
  за один год из четырёх, даёт **одну** колонку; тест краснеет на

## B3. Запуск без терминала — воспроизводимо, а не однажды

Сейчас пользователь запускает `python3`, и рядом с окном живёт
терминал. Собранное приложение существует (`dist/EquityLab.app`), но
собрано однажды, из старого кода, а его spec-файл внесён в
`.gitignore` — то есть сборка **не воспроизводится из репозитория**.
ТЗ-C10 это засчитало «структурно»; пользователь просит по-настоящему.

**Done when:**
- spec-файл (или скрипт сборки) **лежит в репозитории** и больше не
  игнорируется; строки из `.gitignore`, которые его прятали, сняты —
  `build/` и `dist/` остаются игнорируемыми;
- одна команда из `README`/`GUIDE` собирает `.app`, который
  открывается двойным щелчком **без единого окна терминала**; ключ
  `--windowed` (или его эквивалент в spec) назван явно;
- приложение находит каталог данных пользователя; каталога нет —
  говорит словами, что сделать, а не падает;
- динамическая линковка Qt сохранена (LGPL, ADR-0004) и проверена —
  назови, чем;
- smoke-тест сборки по маркеру: собранное приложение стартует и
  закрывается с кодом 0; в обычном прогоне пропускается;
- честная граница повторена в отчёте: подпись и нотаризация не
  делаются (платно, ADR-0018) — скажи, что это значит при первом
  запуске и какой командой снимается карантин.
