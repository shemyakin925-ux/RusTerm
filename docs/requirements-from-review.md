# Требования, принятые по итогам внешней рецензии

Источник — внешняя рецензия спецификации от 05.09.2026 и её разбор.
Сами документы рецензии удалены вместе с материалами прошлой, российской
версии проекта; принятые требования вынесены сюда в рыночно-нейтральном виде
и обязательны к исполнению.

## Принято к исполнению

1. **Явная линия отсечения MVP.** Roadmap — не ТЗ на первый релиз. Что входит
   в MVP, сформулировано одной фразой, всё остальное явно отложено.
   → README §15, критерий готовности MVP.
2. **Data lineage на каждое число, а не только на governance.** Источник, URL,
   дата выгрузки, версия парсера, ссылка на сырьё.
   → ADR-0001.
3. **Версионирование всех формул**, а не только весов governance: Total Return,
   ROIC, перцентили. Иначе через год свои же цифры не воспроизводятся.
   → ADR-0001, `method_version`.
4. **Observability слоя сбора.** Success rate по провайдерам, лаг данных, доля
   фактов со статусом `suspect`, доля событий, ушедших на ручную верификацию.
   → Фаза 3.
5. **Процедура исправления ошибок извлечения и хранилище ground truth.** Роль
   верификатора: пользователь помечает число неверным, правка сохраняется как
   отдельный факт с приоритетом над извлечённым и участвует в golden-file.
   → Фаза 3, требует отдельного ADR.
6. **Экспорт в CSV / Excel.** Дёшево, а при работе с сотнями бумаг
   обязательно. → README §5.5, Фаза 3.
7. **UX-сценарии вместо перечня таблиц.** Продукт описывается задачами
   пользователя, а не набором блоков. → README §5.6, требует расширения.
8. **Threat model источников.** Что делаем, если провайдер закроет бесплатный
   доступ, сменит формат или введёт лимиты. Fallback на каждый источник.
   → требует отдельного ADR до Фазы 2.

## Отклонено с обоснованием

- **«Governance стоит вынести в отдельный продукт».** Governance — единственное,
  что отличает терминал от бесплатного скринера. Остаётся в составе.
- **«Реестр обещаний эмитента восстановим только вперёд».** Годовые отчёты
  за 5-10 лет доступны и содержат дивполитику, гайденс и стратегические цели —
  для 10-20 эмитентов это восстановимо ручной работой. Невосстановимы
  презентации и прошлые версии IR-страниц, то есть «тихие отмены». Эти два
  случая разделяются.

## Закрытые вопросы

- **Оболочка UI:** нативный десктоп на PySide6 — ADR-0004.
- **Хранилище:** SQLite, локальный каталог данных — ADR-0003.
- **Потолок MVP:** 500 бумаг.

## Открытые вопросы

- **Governance:** с первого дня на эталонной выборке 20 эмитентов либо
  после выхода на полное покрытие данных по всем 500.

## Правовое замечание

Риск иска о защите деловой репутации со стороны крупного акционера на
governance-оценку. В текущем режиме (локальное приложение, никому не
раздаётся) риск близок к нулю; при публичной раздаче требует проработки
**до**, а не после. → README §16.
