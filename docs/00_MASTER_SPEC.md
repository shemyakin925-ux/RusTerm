# RusEquity Terminal — Master Specification

## 1. Overview

**RusEquity Terminal** — кросс-платформенное (Desktop + Mobile) приложение для глубокого анализа российских акций (MOEX).

### Ключевые принципы

- **Только бесплатные источники данных**: MOEX ISS, e-disclosure, RFSD, сайты эмитентов.
- **Total Return**: расчёт полной доходности (цена + дивиденды).
- **Мощная аналитика**: valuation percentiles, ROIC/productivity, factor scores, relative strength, dividend consistency и др.
- **AI-слой**: поддержка remote API и локальной LLM.
- **Архитектура**: изначально расширяема до Bloomberg-класса.
- **Frontend**: один codebase для телефона и компьютера (Flutter).

## 2. Multi-LLM Development Process

Проект разрабатывается поэтапно разными LLM с обязательной перепроверкой друг друга.

### Правила

1. **Одна LLM = одна атомарная задача / одна фаза.**
2. **Перед началом работы LLM обязана прочитать:**
   - `00_MASTER_SPEC.md`
   - `03_ARCHITECTURE.md`
   - `15_AGENT_RULES.md`
   - `16_NEXT_TASK.md`
   - `17_VERIFICATION_PROTOCOL.md`
3. **Запрещено** добавлять платные источники данных.
4. **Запрещено** делать архитектуру «на вырост» сверх текущей фазы.
5. **Любое отклонение** от утверждённой архитектуры — только через ADR в `09_DECISIONS.md`.
6. **После завершения задачи LLM обязана:**
   - Обновить `01_PROJECT_STATUS.md`
   - Обновить `11_CHANGELOG.md`
   - Написать отчёт о проделанной работе
   - Оставить репозиторий в состоянии, готовом к проверке следующей LLM.
7. **Следующая LLM не имеет права продолжать разработку**, пока не выполнит проверку по `17_VERIFICATION_PROTOCOL.md`.

## 3. Цели проекта

1. Предоставить инвесторам инструмент для глубокого анализа российских акций.
2. Обеспечить расчёт Total Return с учётом дивидендов.
3. Реализовать аналитику уровня Bloomberg на основе открытых данных.
4. Поддержать работу на Desktop и Mobile с единой кодовой базой.
5. Интегрировать AI-ассистента для генерации инсайтов.
