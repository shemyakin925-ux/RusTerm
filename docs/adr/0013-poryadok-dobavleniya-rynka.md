# ADR-0013. Порядок добавления рынка: цена седьмого рынка, измеренная на десяти полосах

**Статус:** принято (координатору на утверждение; написан полосой L10,
ТЗ-20, 12.09.2026). Развивает ADR-0010; не отменяет ничего.

## Контекст

ADR-0010 обещал: «стоимость следующего рынка — строка в MARKETS, файл
провайдера, записанный payload». Ночью ТЗ-20 обещание проверено
делом: четыре рынка (KR, BR, AU, углубление OTC) строились десятью
полосами, и цена каждого шага теперь измерена, а не обещана. Этот ADR
фиксирует процедуру добавления рынка номер семь и дальше — из
фактических затрат ночи, не из теории.

## Решение

**Рынок номер семь добавляется семь шагами, и цена каждого известна
заранее.**

### Шаги и их измеренная цена (ночь 11→12.09.2026)

| Шаг | Что делается | Измеренная цена |
|---|---|---|
| 1. Строка реестра | `MARKETS` + `access` (ADR-0010 §2); провайдер может не существовать — место сядет реестр | минуты (сделано заранее, ТЗ-19 F1) |
| 2. Живой замер | запрос-два на хост: точный URL, статус, байты — в отчёт | 2 запроса, ~30 минут |
| 3. Провайдер-модуль | `build(gate)`, свой `HostLimit` (темп из замера), `DisclosuresProvider`, `can_auto_ingest` с тремя исходами | 1–2 часа; сетевой код только здесь (проверка 8) |
| 4. Записанный payload | настоящие байты, нарезка ≤256 КБ на полосу, золотые значения разрешаются в файл указателем | 30–60 минут; архивы в git не попадают (N5) |
| 5. Тесты на записанных телах | сеть в тестах — только с ключом, без ключа — скип (N7); refusal-пути наравне с happy-path | входит в шаг 3 |
| 6. Таксономия | тега нет в словаре — `Blocked`-строка полосы; закрывается отдельным проходом по `concepts.py`, не полосой | 0, если рынок готов отдавать известные теги |
| 7. Приёмка | `agent/selfcheck.sh` на СВОЕЙ ветке — 13/13 | ~2 минуты на прогон |

### Чему научила ночь (в порядке важности)

1. **Форма набора данных меняется у источника, а не у нас.** Набор
   DFP-2024 у CVM оказался индексом документов + ведомыми файлами
   (DRE/BPP), а не плоским построчником, каким он описан в замерах
   сообщества. Урок: golden-тест должен пинить имена ключей/членов —
   переименование на стороне источника будет громким.
2. **Форма блокировки дрейфует.** `/content` у OTC 09.09 отвечал
   200 с HTML-заглушкой, 11.09 — уже 406. Блок — стоп в любой форме
   (N4); тест фиксирует обе формы как `source_unreachable`.
3. **Ключ — не деталь, а половина полосы.** L1 (Корея) и живые таблицы
   L7 отработали офлайн-половину: код и тесты готовы, золотых payload
   нет. Регистрировать ключи ДО ночи — самый дешёвый способ удвоить
   результат ночи.
4. **Внутриполосный порядок — часть контракта.** L6 ветвился от головы
   L5, потому что импортирует её модуль: единственное упорядочение
   фан-аута («L5 раньше L6») при таком-base делает слияние
   бесконфликтным по построению.
5. **Общий файл, который устарел вместе с местом, — предсказуемый
   конфликт.** Пин «провайдер не реализован» умер в момент заполнения
   места; lifecycle-форма теста (одинаковая на всех полосах) снимает
   вопрос навсегда.

### Что делать рынку номер семь (чек-лист)

1. Замерить канал по форме REPORT-MARKETS; нет машинного доступа —
   рынок получает `access: manual` и путь ADR-0011, а не провайдера.
2. Строка в `MARKETS` с `access`; место в `_NETWORK_PROVIDERS` —
   лямбдой с импортом внутри вызова (ADR-0012 §2).
3. Модуль `rusterm/providers/<код>.py`: `build(gate)`, свой HostLimit,
   `can_auto_ingest` до создания эмитента, ошибки — значения.
4. Записанный payload ≤256 КБ + golden-тест по указателю.
5. Таксономические дыры — списком в отчёт полосы; закрывает
   интеграция одним проходом.
6. Полоса заканчивается `READY TO MERGE` и зелёной приёмкой своей
   ветки; слияние — по ADR-0017.

### Таксономические дыры, собранные ночью (для ТЗ-21)

- BR: строки DRE/BPP несут собственные колонки (CD_CONTA, DS_CONTA,
  VL_CONTA, ESCALA_MOEDA) — отображение на словарь `ifrs-full` не
  построено (вне зоны полосы; интеграция).
- KR: реальные теги неизвестны до ключа — список будет после первого
  живого прогона с `RUSTERM_DART_KEY`.
- AU/OTC: заявленных XBRL-тегов нет (JSON-метаданные), дыр нет.

## Следствия

- Цена седьмого рынка известна: примерно полчаса замера + два-три часа
  провайдера с тестами + payload. Два дня реальной работы «под ключ»
  (регистрация, первый живой прогон, таксономия) — вне ночной смены.
- Обещание ADR-0010 подтверждено с поправкой: «одна строка реестра» —
  это регистрация; рыночная логика и правда не переписываются, но
  добротный провайдер с записанными телами и refusal-путями стоит
  измеренных часов, и скрывать это не нужно.
- Форма блокировки и форма набора данных у источника — дрейфующие
  величины; их ловят golden-тесты, а не человек.
