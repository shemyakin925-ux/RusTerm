# ADR-0001. Доступ к раскрытию информации эмитентов

**Статус:** принято частично (05.09.2026). Вопрос о канале до e-disclosure остаётся открытым.

## Контекст

Замер (см. `spikes/01-disclosure-access/FINDINGS.md`):

- e-disclosure.ru (Интерфакс) недоступен с канала пользователя в Дананге —
  соединение рвётся на сетевом уровне, сайт не открывается и вручную в браузере.
  С датацентровых IP сервер отвечает 403 на всё, включая robots.txt.
- Доступны напрямую: disclosure.skrin.ru, disclosure.1prime.ru, disclosure.ru (АК&М).
  Каждое агентство обслуживает только своих клиентов; голубые фишки — у Интерфакса.
- disclosure.azipi.ru не существует, из списка источников исключён.
- iss.moex.com доступен и отдаёт `emitent_inn` вместе с инструментом,
  чем закрывается связка «бумага ↔ юрлицо ↔ раскрытие» без ручного справочника.
- Ни облачный контейнер (egress-allowlist), ни локальная Linux-VM (нет сети)
  для сбора не годятся в принципе.

## Решение

**Платный подписной REST API Интерфакса — целевой источник раскрытия, но
подключается только после того, как проект подтвердит свою состоятельность.**
До этого момента деньги в источник не вкладываются.

Обоснование: API снимает разом гео-фильтр, хрупкий парсинг вёрстки и правовой
вопрос с перераспространением, но пока не доказано, что продукт нужен и работает,
это преждевременная трата. Критерий «состоятельности» подлежит определению
отдельно; разумный кандидат — пройденная Фаза 4 (governance разделяет эталонные
20 эмитентов) на том покрытии, которое доступно бесплатно.

## Следствия

1. В `sources/` закладывается интерфейс `DisclosureProvider` с реализациями
   на агентство. Переход на API Интерфакса не должен затрагивать `ingestion/`
   и выше — это тот же приём изоляции, что и `MarketDataProvider` для котировок.
2. Слой сбора физически отделён от обработки: он исполняется на узле с сетевым
   доступом, обработка — где угодно. Проектировать как обмен файлами через
   raw-store, а не как единый процесс.
3. Покрытие по governance до подключения API будет неполным, и это надо
   показывать в UI как `coverage`, а не замалчивать.

## Открытый вопрос

Чем закрывается период до подключения API: узел с российским выходом
(VPS или VPN) либо работа только по трём доступным агентствам.
Решение не принято.
