# ADR-0015. Порядок добавления сектора — измеренный на втором секторе

**Статус:** принято (ТЗ-24 N10/N11, 12.09.2026). Выведен из практики
добавления mining после maritime_tanker, а не из воображения.

## Контекст

TASK-8 U12.1 связал имена функций модуля отрасли с каталогом
`docs/industry-metrics/<sector>.md`. Один сектор ничего не доказывает
о процедуре: второй (mining) стоил измерений, которые записаны здесь.

## Измеренная стоимость добавления сектора

| Шаг | Что делается | Механика или суждение |
|---|---|---|
| 1 | Каталог метрик: имена, единицы, входы | **суждение** — читать годовые отчёты сектора; механики нет |
| 2 | `rusterm/core/industry/<sector>.py` с `METHOD_VERSION` и функциями по каталогу | механика: каждая функция — деление/процент с правилами null; шаблон maritime/mining |
| 3 | `PHYSICAL_INPUT_MAP[sector]` — псевдонимы записей -> имена входов | **суждение** — как сектор называет «off-hire days» в своих отчётах; остальное механика |
| 4 | `EXPECTED_BASE_UNITS[sector]` + `METRIC_INPUTS[sector]` (входы каждой метрики) | механика после шага 1 |
| 5 | Строка в `SECTOR_MODULES` (industry/__init__.py) | механика, одна строка |
| 6 | Фикстуры: синтетическая страница + записи manual_extraction | механика |
| 7 | Каталожная страница в docs/ | **блокировано пунктом 10** (см. ниже) |

## Решения, к которым привели измерения

1. **Каталожная страница живёт в докстринге модуля**, а не в
   `docs/industry-metrics/`: пункт 10 приёмки пускает в docs/ только
   новые `docs/adr/`; добавленный файл вне `docs/adr/` валит приёмку
   (измерено на mining: `A docs/industry-metrics/mining.md` вне
   шаблона `^A docs/adr/` — см. Disputed REPORT-24.md). Если пункт 10
   когда-нибудь ослабят до «новые ADR + каталоги отраслей», страницу
   можно вынести обратно без изменения кода: имена в модуле уже
   дословно каталожные.
2. **Входы метрик объявляются явно** (`METRIC_INPUTS`), а не
   вычитываются из сигнатур: диспетчер maritime принимает `**kw`,
   имена входов в нём не выражены.
3. **Реестр секторов ключуется id peer set** («tankers», «mining»),
   а не именем модуля: сектор инструмента — это его отраслевой
   peer set (M7).

## Следствия

- Третий сектор — шаги 1-7, без правок snapshot/tools/TUI: проводка
  универсальна с ТЗ-24.
- Суждение сосредоточено в шагах 1 и 3 (прочитать сектор и его
  терминологию); всё остальное — механика по шаблону.
