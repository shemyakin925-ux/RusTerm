# Каталог отраслевых метрик

Этот каталог описывает **специфичные метрики по отраслям**, которые
добавляются к стандартному фундаментальному набору (выручка, EBITDA,
прибыль, маржа, ROIC, мультипликаторы).

Формат файла на каждую отрасль — ниже. Цель каталога: при добавлении
нового сектора в приложение (через Industry View, peer comparison,
снапшот компании) — взять готовый набор метрик, источников, сложностей
извлечения и golden-file тестов, а не изобретать с нуля.

---

## Структура файла отрасли

```markdown
# Industry: <Название>

## Стандартные метрики
(применить общую схему: выручка, EBITDA, Net Income, ROIC, маржи, долг)

## Специфичные метрики
- metric_name — описание, формула, единицы
- ...

## Источники
- Annual report segment disclosure
- Operational releases
- Quarterly / half-yearly updates
- Регуляторные публикации (для regulated отраслей)

## Сложности извлечения
- Сегментация меняется год от года
- Нестандартная терминология (TCE, AISC, NIM...)
- Зависимость от внешних индексов (Baltic Dry, IMO bunker price)

## Тесты
- Golden-file на 3-5 эмитентах
- Unit на расчётные метрики (per-ship, per-asset, per-customer)
- Интеграционный на получение данных из источника

## Peer set по умолчанию
(список прямых конкурентов для первого запуска)
```

## Принципы расширения каталога

1. **Один файл = одна отрасль.** Не группировать «Maritime» в один
   файл с 50 метриками — лучше tanker.md, container.md, bulk.md.
2. **Минимум 5 специфичных метрик на отрасль.** Если меньше — сектор
   не заслуживает отдельного файла, хватит стандартного набора.
3. **Источник на каждую метрику.** Без источника — метрика
   не идёт в каталог.
4. **Сложности обязательны.** Если сложностей нет — метрика либо
   тривиальная, либо мы чего-то не понимаем.
5. **Golden-file на 3 эмитентах.** Без него — метрика в каталоге,
   но не в MVP.

## Связь с peer sets

Каждой отрасли из каталога соответствует **peer set по умолчанию**
(см. Maritime / Tanker — пример выше). Peer set — это файл
`data/peers/<ticker>.json`, переопределяется пользователем.
