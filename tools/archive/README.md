# Архиватор раскрытия — Фаза 0a

Сохраняет байты, пока они существуют. Ничего не парсит: страницы эмитентов
перезаписываются без следа, и версию, не скачанную сегодня, завтра взять
неоткуда. Разбор — потом и по сохранённым файлам.

## Как устроено

- `run.sh` — обёртка: проверяет канал, потом запускает сбор.
- `archiver.py` — сбор. Тела кладутся в `data/raw/store/<2 знака>/<sha256>`,
  каждый запрос описывается строкой в `data/raw/manifest/<ГГГГ-ММ>.jsonl`.
- `targets/*.txt` — что скачивать, формат `метка<TAB>URL`.

Дедупликация по хешу даёт версионирование бесплатно: неизменившаяся страница
не занимает места повторно, изменившаяся появляется новым объектом. Момент
изменения виден по манифесту — именно так ловится «тихая отмена» обещания.

## Защита канала

Перед сбором `run.sh` запрашивает главную e-disclosure и требует 200.
Не 200 — **проход отменяется целиком**, код возврата 2, в лог пишется внешний
адрес. Полдня архива хуже, чем его отсутствие: неполный день неотличим от дня
без новостей, а именно на этом строятся governance-метрики.

Проверка функциональная, а не географическая: она спрашивает не «российский ли
адрес», а «пускает ли нас Интерфакс». Это то, что нужно на самом деле.

## Запуск

```sh
# поднять VPN с российским выходом, затем:
bash tools/archive/run.sh

# посмотреть список целей, ничего не скачивая:
python3 tools/archive/archiver.py --targets targets/edisclosure.txt \
        --root data/raw --dry-run
```

Ежедневно, через launchd:

```sh
cp tools/archive/com.rusterm.archiver.plist ~/Library/LaunchAgents/
launchctl bootstrap gui/$UID ~/Library/LaunchAgents/com.rusterm.archiver.plist
launchctl kickstart -p gui/$UID/com.rusterm.archiver   # проверить сразу
```

Время в plist — 21:30 по местному. **launchd не разбудит спящий Mac и не
поднимет VPN**: пропущенный проход виден в логе как отсутствие записи,
и это единственная известная слабость схемы.

## Проверено

Прогон на локальном сервере: новый объект сохраняется, повторный запрос
не дублирует, изменённая страница фиксируется новым хешем, 404 и отказ
соединения пишутся в манифест без падения прохода. Защита канала протестирована
в среде без сети — отменяет проход с кодом 2.

**Не проверено:** ни один живой ответ e-disclosure. Сайт недоступен из Вьетнама,
разметку его страниц не видел никто. Список целей — только точки входа;
карточки эмитентов достраиваются после первого удачного прохода по
сохранённому HTML.
