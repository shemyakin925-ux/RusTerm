# Спайк 01 — доступ к серверам раскрытия

**Зачем.** На доступности раскрытия стоит вся Фаза 0a и governance-модуль.
С датацентровых IP e-disclosure.ru отдаёт 403 на всё, включая robots.txt, —
проверено двумя независимыми клиентами. Неизвестно главное: пускает ли он
домашний IP. От ответа зависит, идём мы прямым путём или строим роутинг по
пяти уполномоченным агентствам с неполным покрытием.

**Где запускать.** Только в обычном Терминале macOS. Ни облачный контейнер
(egress-allowlist), ни локальная Linux-VM (сети нет вовсе) для этого не годятся —
и это же означает, что боевой архиватор Фазы 0a тоже будет launchd-джобой на Mac.

```sh
cd spikes/01-disclosure-access
bash probe.sh                        # пауза 3с, 15 запросов в rate-тесте
DELAY=5 RATE_N=30 bash probe.sh      # мягче и глубже
```

**Что получится.** `out/<таймстамп>/report.md` — четыре ответа: пускает ли IP,
нужен ли JS, где начинается rate limit, какие запасные серверы живы.
Рядом `raw/` — сырые тела и заголовки всех ответов, с копией в UTF-8 там,
где сервер отдал windows-1251. Разбирать потом будем по этим файлам, а не
по живому сайту: принцип «сначала сохранить байты, потом парсить» действует
с первого дня.

`out/` в git не попадает. Папка `out/DRYRUN-no-network/` — холостой прогон
в песочнице без сети, все коды 000; это проверка механики скрипта, а не
результат замера.

**Нагрузка.** Порядка 15 одиночных запросов с паузой 3 секунды —
меньше, чем создаёт человек, листающий сайт руками.
